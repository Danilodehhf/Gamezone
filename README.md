# GameZone — HTML, CSS e JavaScript puro

Este projeto não usa React, Vite, npm ou Node.js.

## Estrutura
- Inicio.html
- Jogos.html
- Sobre.html
- Fontes/
- Imagens/

## Como executar
Abra `Inicio.html` diretamente no navegador.

Se preferir usar um servidor local simples, qualquer servidor HTTP estático funciona,
mas não há instalação de dependências nem processo de build.
